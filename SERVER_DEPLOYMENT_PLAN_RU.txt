ПЛАН ПЕРЕНОСА ATLAS НА СЕРВЕР — НЕ ИНСТРУКЦИЯ К ПУБЛИКАЦИИ ТЕКУЩЕГО КОДА

1. Сохранить локальную 4.8 и проверить экспорт SQLite с SHA-256.
2. Подготовить Linux VPS, отдельного непривилегированного пользователя, обновления ОС и firewall.
3. Переработать приложение для запуска за HTTPS reverse proxy (Caddy/Nginx), не доверять X-Forwarded-* без проверки доверенного прокси.
4. Обновить проверку Host/Origin для HTTPS и разрешённого домена; настроить Secure, HttpOnly, SameSite cookies, CSRF-защиту и строгие лимиты запросов.
5. Хранить секреты вне кода; добавить восстановление сессий после перезапуска, безопасный сброс пароля, журнал доступа.
6. Перенести базу через проверенный бэкап; для многопользовательского облачного доступа оценить PostgreSQL, транзакции и блокировки.
7. Настроить ежедневные зашифрованные бэкапы вне сервера, тест восстановления и мониторинг.
8. Провести отдельный тест безопасности до публичного доступа.

Текущая версия 4.8 работает локально по HTTP и не должна быть открыта в интернет.
