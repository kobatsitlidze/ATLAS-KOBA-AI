ATLAS 4.6 — тест доступа с телефона по Wi-Fi

1. Для первого входа и создания пароля используйте START_ATLAS.bat.
2. Подключите ноутбук и телефон к одной ДОВЕРЕННОЙ Wi-Fi сети (не гостевой).
3. Закройте обычный ATLAS. Запустите START_ATLAS_PHONE_WIFI.bat.
4. В чёрном окне появится АДРЕС ДЛЯ ТЕЛЕФОНА: http://192.168.x.x:8765/login
5. Откройте этот адрес в браузере телефона и войдите с прежним паролем.
6. Ноутбук должен оставаться включённым, окно программы — открытым.
7. Если Windows Firewall спросит разрешение, разрешайте только для ЧАСТНОЙ сети. Не разрешайте публичные сети.
8. Если телефон не подключается, проверьте, что устройства в одной Wi-Fi сети и что роутер не изолирует клиентов.

ВНИМАНИЕ: это ТОЛЬКО тест внутри доверенной сети. HTTP не шифрует пароль и данные. Не используйте общественный Wi-Fi, не делайте переадресацию порта на роутере, не открывайте доступ через интернет. Для реального удалённого доступа потребуется HTTPS/VPN.
База данных и её резервные копии остаются в прежнем каталоге Windows AppData; копировать базу в папку 4.6 не нужно.
