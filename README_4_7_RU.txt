ATLAS & KOBA 4.7 — SERVER PREP

1. Сохраните работающую папку 4.6 отдельно.
2. Распакуйте 4.7 в НОВУЮ папку.
3. START_ATLAS.bat — локальный запуск, START_ATLAS_PHONE_WIFI.bat — доступ с телефона через личную точку доступа.
4. EXPORT_BACKUP.bat — ручная резервная копия базы в Documents\ATLAS_EXPORTS. Скрипт использует штатный SQLite backup API и проверяет integrity_check, структуру таблиц и SHA-256. Исходная база НЕ изменяется.
5. НЕ отправляйте файл базы, auth.json или копии посторонним. Не размещайте их в общедоступном облаке.

ВНИМАНИЕ: это подготовка, а НЕ готовый облачный сервер.
Для размещения потребуются отдельные HTTPS, домен, управление секретами, серверная аутентификация, ограничения доступа, защищённое хранилище и испытание восстановления.
Нельзя открывать порт 8765 в интернет: текущие cookie не Secure и HTTP не шифруется.
Не используйте публичную Wi-Fi сеть для LAN-режима.
