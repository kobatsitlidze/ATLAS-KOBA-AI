## Цель пользователя
Единый персональный агент ATLAS GLOBAL: работа 24/7, доступ из разных стран через мобильный и десктопный интерфейс, Gmail, WhatsApp, календарь, документы, гостиничные процессы и PMS при наличии законных и технических интеграций. Сохранить прежнюю функциональность и историю. Основной язык разработки — Python; Laravel не требуется без доказанной необходимости.

## Архитектурная гипотеза (ещё не утверждённая реализация)
- Python backend (например, FastAPI), защищённый HTTPS API.
- PWA для мобильного и десктопного доступа.
- PostgreSQL для облачного развёртывания; миграция SQLite с проверкой целостности.
- Очередь фоновых заданий, журнал действий, мониторинг, резервные копии.
- OAuth для Gmail/Calendar; официальный WhatsApp Business Platform при наличии подходящего аккаунта.
- LLM-провайдер выбирается отдельно с учётом цены, приватности и требований; отсутствие Ollama в 4.0 — установленный факт.
- Локальный шлюз Windows только для систем без удалённого API.

## Политика безопасности
Никакого прямого открытия текущего HTTP-сервера в интернет. Вход с MFA, разграничение ролей, секреты вне исходного кода, минимальные разрешения. Отправка важных сообщений, платежи, изменения цен и удаление данных — с согласованием. Данные гостей и сотрудников — с контролем доступа и сроками хранения.

## Следующие проверяемые этапы

6. Фоновые задания, мониторинг и безопасное облачное развёртывание.
